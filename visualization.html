💡 ReCode 是什么？

ReCode 是一个智能 AI 系统，它能把复杂的任务自动拆解成一步步的小任务， 就像你在做菜时会把"做西红柿炒鸡蛋"拆成"准备食材"、"烹饪"、"装盘"一样。

⚡ ReCode vs 传统方法

特性 ReCode 传统方法
规划方式 ✅ 动态规划，边做边调整 ❌ 静态规划，无法中途改变
任务分解 ✅ 自动递归分解 ❌ 需要手动设计
错误处理 ✅ 根据反馈调整策略 ❌ 遇到错误就失败
可追溯性 ✅ 完整的执行树 ❌ 黑盒操作
粒度控制 ✅ 自适应调整 ❌ 固定粒度

💻 代码示例

# ReCode 生成的代码树示例 # 根节点：总任务 solve(instruction, observation) # AI 自动分解为三个子任务 ├── target = find_mug(observation) ├── pick_up(target) └── place_on_desk(target) # 子任务继续分解为具体动作 find_mug: ├── obs1 = run("go to cabinet 1") ├── obs2 = run("open cabinet 1") └── obs3 = run("look") pick_up: └── run("take mug 1 from cabinet 1") place_on_desk: ├── run("go to desk 1") └── run("put mug 1 in/on desk 1")

🚀 快速开始

安装和运行

# 1. 克隆仓库 git clone https://github.com/your-username/ReCode.git cd ReCode # 2. 安装依赖 pip install -r requirements.txt # 3. 配置 LLM API（编辑 configs/profiles.yaml） # 添加你的 OpenAI API Key # 4. 运行测试 python run.py -a recode -e alfworld -n 1 --profile default # 5. 查看结果 # 结果保存在 logs/ 目录下
